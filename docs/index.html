DEPLOYMENT

Deploy your bot.

Use the Heroku deployment template for this project, then add your own session ID privately in the deployment configuration.

  1. Open the Heroku deployment form.
  2. Choose an app name and review configuration.
  3. Enter your own SESSION_ID privately.
  4. Check build and runtime logs to confirm the bot starts and connects.

Secret safety: Never publish API keys or WhatsApp session IDs in GitHub, website text, screenshots, or public chats. A personal Heroku API key is not required for ordinary bot deployment.
