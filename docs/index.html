DEPLOYMENT

Choose your hosting.

Choose a platform below. The official Levanter README links both Koyeb and Render deployment flows through the Levanter deployment page. Follow the platform's setup steps and enter your own WhatsApp session ID only in the private environment-variable form.

Deploy to Heroku ↗Deploy to Koyeb ↗Deploy to Render ↗
  1. Select your hosting platform and connect your own account.
  2. Configure the service using the platform's deployment instructions.
  3. Add your own SESSION_ID privately as an environment variable.
  4. Check build and runtime logs to confirm the bot starts and connects.

Secret safety: Never publish API keys or WhatsApp session IDs in GitHub, website text, screenshots, or public chats. A personal Heroku API key is not required for ordinary bot deployment.
